# KeyCanvas artwork

The KeyCanvas mark is an original vector created for this project. It combines
an abstract keycap with three light ribbons to represent remapping, color, and
motion. It is not based on the keyboard vendor's logo, driver artwork, UI, or
product packaging.

`keycanvas-mark.svg` is distributed under the repository's MIT license.

The source SVG is the canonical asset. Release packaging may rasterize it into
the standard macOS icon sizes without changing its license.
